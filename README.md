Cyber Pulse: Neon Dodger is a high-velocity cyberpunk retro arcade canvas game. Dodge falling quantum hazard spikes, collect cyber energy orbs, and deploy EMP Overdrive shockwaves across 12 escalating sectors.

## Run it

Serve locally:
```sh
node serve.ts
```
Then open `http://localhost:8080` in a desktop browser.

Build output dossier:
```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
